MY DAILY HISAB - ANDROID-FRIENDLY APP STARTER

Included:
- Shop / Personal / All filters
- Add, edit, delete income and expense records
- Daily and monthly filtering
- Income, expenses and net balance totals
- JSON backup and restore
- CSV export
- Offline caching after first load

IMPORTANT:
This is an installable web app (PWA) starter, not a compiled APK. To install it on Android:
1. Host this folder on an HTTPS website (for example, a static hosting service).
2. Open the website in Chrome on Android.
3. Open Chrome menu and choose "Install app" or "Add to Home screen".

Records are stored in this browser on this device. Use Backup regularly and keep the JSON file somewhere safe. For cross-device cloud sync, a secure backend and sign-in need to be added.
